Window

macOS-native from the first pixel

The window lives in your menu bar — click the icon to show or hide it. The red button hides the panel without quitting; the app keeps running and polling in the background. Pin the window to keep it on top while you work.

Sections

Yours and theirs, at a glance

Your PRs shows everything you authored that's still open. Others' PRs shows every other open pull request in the repos you work in — not just the ones where your review was explicitly requested. You see the full team queue without having to open GitHub.

CI

Every check run, grouped by workflow

Click the chevron on any PR to see all its CI jobs, grouped by workflow. Running jobs show a live spinner. Each job links directly to its run page — one click to see why it failed.

Duplicate runs from re-opened PRs are automatically deduplicated — you always see only the latest run per job.

Filter

Hide the noise, focus on what matters

The filter dropdown lets you choose which repos to show. Uncheck a repo and its PRs disappear from both sections instantly. The filter is saved to your preferences — it persists across restarts.

Preferences

Set it and forget it

Launch at login starts PR Monitor automatically when you log in — no need to remember to open it. Start minimised skips the window on launch; just the tray icon appears. Preferences are saved to ~/Library/Application Support/PR Monitor/.

Get Started

Three commands. That's it.

No Xcode. No certificates. No App Store.

# 1. Install GitHub CLI and authenticate brew install gh && gh auth login
# 2. Clone the repo git clone https://github.com/jeanjacquesaka1980/pr-monitor.git cd pr-monitor
# 3. Install and launch npm install && npm run start

The ghost icon appears in your menu bar. That's it.
